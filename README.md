# Полигон

Платформа для тестирования текстовых и голосовых ИИ-агентов, которые общаются с клиентами и выполняют действия в бизнес-системах.

Полигон создаёт условия испытания, моделирует поведение клиента и сохраняет диалог, вызовы инструментов и изменения данных. Результат — отчёт, который помогает найти ошибку, разобраться в её причинах и сравнить версии агента.

**Статус:** проект находится в разработке.

## Зачем нужен Полигон

Ответ агента «заявка создана» ещё не доказывает, что операция прошла правильно. Например, бизнес-система может сохранить заявку и вернуть тайм-аут, а агент при повторном запросе создаст дубликат.

Полигон предназначен для проверки таких ситуаций в изолированной тестовой среде. Он связывает слова агента с его действиями и фактическим результатом, помогая различать ошибки агента, технические сбои и случаи, когда данных для вывода недостаточно.

## Компоненты

| Компонент | Назначение |
|---|---|
| [Platform](platform/README.md) | Управление проектами, версиями агентов, сценариями и тестовыми запусками |
| [Runner](runner/README.md) | Исполнение тестовых сессий, подключение к агенту и запись хода испытания |
| [Environment](environment/README.md) | Изолированная бизнес-среда с тестовыми данными и управляемыми сбоями |
| [Intelligence](intelligence/README.md) | Симуляция клиента и оценка результатов испытания |
| [Frontend](frontend/README.md) | Веб-интерфейс для запуска тестов, просмотра отчётов и сравнения версий |

## Как устроено испытание

Пользователь выбирает версию агента и сценарии в веб-интерфейсе. Platform создаёт запуск, Runner проводит разговор и направляет действия агента в Environment. Intelligence формирует реплики клиента и оценивает собранные результаты. Отчёт показывает, какие проверки пройдены и какие действия привели к ошибке.
