# Platform

Сервис управления проектами и тестовыми запусками Полигона. Предоставляет публичный API для веб-интерфейса и координирует выполнение испытаний.

Основные задачи:

- Управление пользователями, проектами и правами доступа.
- Хранение версий агентов, сценариев и настроек испытаний.
- Создание, отслеживание и отмена тестовых запусков.
- Назначение исполнения и оценки, обработка результатов.
- Предоставление отчётов, прогресса и сравнения версий агента.

Platform передаёт исполнение сессий Runner, а оценку результатов — Intelligence. Объединяет их результаты в согласованное состояние запуска и предоставляет доступ к материалам испытания.
