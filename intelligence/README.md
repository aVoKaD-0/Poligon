# Intelligence

Сервис симуляции клиента и оценки результатов испытаний. Формирует поведение собеседника агента и проверяет, достигнута ли цель сценария.

Основные задачи:

- Генерация реплик клиента по сценарию и текущему диалогу.
- Поддержка заданных последовательностей реплик и модельной генерации.
- Проверка бизнес-результата по состоянию среды и журналу действий.
- Оценка качества диалога и корректности самой симуляции.
- Формирование результатов проверок с объяснениями и ссылками на доказательства.

Во время разговора Intelligence отвечает на запросы Runner. После исполнения получает задание на оценку от Platform и анализирует сохранённые материалы. Результат учитывает полноту данных: недостаток доказательств должен быть виден в отчёте.
