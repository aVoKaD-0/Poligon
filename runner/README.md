# Runner

Сервис исполнения тестовых сессий. Подключает проверяемого агента к синтетическому клиенту и тестовой бизнес-среде, проводит разговор и записывает ход испытания.

Основные задачи:

- Подключение к текстовым и голосовым агентам через адаптеры.
- Передача реплик между агентом и симулятором клиента.
- Выполнение вызовов инструментов агента в Environment.
- Контроль времени, числа действий и остановки сессии.
- Сохранение диалога, вызовов инструментов и аудиозаписей.

Runner получает задание от Platform, использует Intelligence для поведения клиента и Environment для бизнес-операций. По завершении передаёт материалы исполнения для оценки и отчёта.
