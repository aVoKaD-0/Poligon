# Environment

Сервис изолированных бизнес-сред для испытания агентов. Моделирует внешнюю систему, в которой агент работает с клиентами, услугами, временными окнами и заявками.

Основные задачи:

- Подготовка отдельного набора тестовых данных для каждой попытки.
- Предоставление инструментов поиска, создания, изменения и отмены заявок.
- Воспроизведение управляемых сбоев: тайм-аутов, задержек и конфликтов.
- Изоляция данных разных сессий.
- Сохранение итогового состояния и журнала фактических изменений.

Runner направляет действия агента в Environment. Сохранённые данные позволяют Intelligence проверить, что действительно произошло, в том числе когда система изменила данные, но агент получил ошибку.
