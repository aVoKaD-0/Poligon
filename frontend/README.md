# Frontend

Веб-интерфейс Полигона для разработчиков и тестировщиков ИИ-агентов. Объединяет подготовку испытаний, наблюдение за запуском и исследование результатов.

Основные возможности:

- Работа с проектами, агентами и их версиями.
- Подготовка сценариев и настройка тестовых запусков.
- Отображение прогресса и состояния сессий.
- Просмотр диалогов, вызовов инструментов, аудиозаписей и результатов проверок.
- Сравнение версий агента и переход от найденной ошибки к её доказательствам.

Frontend взаимодействует с Platform через публичный API. Интерфейс показывает результаты оценки и помогает отличать обнаруженные ошибки агента от технических сбоев и недостаточных данных.

## Локальный запуск

Из корня репозитория выполните `cd frontend`.

Установите зависимости командой `npm ci` и запустите интерфейс командой `npm run dev`. Команда `npm run build` собирает статические файлы в `dist/`.

## Подключение Platform

Укажите публичный префикс API в `VITE_API_BASE_URL`, например `/api`. Vite читает значение при запуске и сборке. Для `/api` сервер, который отдаёт интерфейс, должен направлять этот путь в Platform. Секреты в переменные `VITE_*` не помещайте.

Предлагаемый контракт адаптера описан в [типах](src/types/poligon.ts) и [API-клиенте](src/api/poligon.ts). После получения OpenAPI Platform сопоставьте маршруты, JSON и авторизацию в этом клиенте.

| Запрос | Ответ |
| --- | --- |
| `GET /catalog` | `Catalog` с доступными сценариями и версиями агента |
| `GET /runs` | `Run[]` с доступными пользователю прогонами |
| `POST /runs` | Принимает `RunConfig`, возвращает `{ id: string }` |
| `GET /runs/{id}` | `RunReport` или HTTP 404 |

В отчёте интерфейс обновляет состояния `queued` и `running` каждые 2,5 секунды. Backend выдаёт идентификаторы и отвечает за проверку прав, запуск, хранение и доступ к результатам. Для публикации согласуйте схему сессии и CSRF с Platform и проверьте права изоляции на реальном API.
