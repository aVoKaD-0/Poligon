# Frontend

Веб-интерфейс Полигона для разработчиков и тестировщиков ИИ-агентов. Объединяет подготовку испытаний, наблюдение за запуском и исследование результатов.

Основные возможности:

- Работа с проектами, агентами и их версиями.
- Подготовка сценариев и настройка тестовых запусков.
- Отображение прогресса и состояния сессий.
- Просмотр диалогов, вызовов инструментов, аудиозаписей и результатов проверок.
- Сравнение версий агента и переход от найденной ошибки к её доказательствам.

Frontend взаимодействует с Platform через публичный API. Интерфейс показывает результаты оценки и помогает отличать обнаруженные ошибки агента от технических сбоев и недостаточных данных.
